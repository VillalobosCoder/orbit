# Orbit

## Desarrollo local

El proyecto usa pnpm y Corepack. Con Node.js instalado, instala las dependencias desde la raíz:

```sh
corepack pnpm install
```

Comandos disponibles desde la raíz:

```sh
corepack pnpm dev
corepack pnpm build
corepack pnpm test
corepack pnpm lint
corepack pnpm typecheck
```
